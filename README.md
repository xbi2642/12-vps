# 饥荒云服务器：内存和单核算清楚，2~12人地面加洞穴照样稳，含开服端口与套餐价格对比

跟朋友玩《饥荒：联机版》玩到第三十天，房主一关电脑，世界就没了。这是本地开服最现实的问题——不是电脑性能不够，是那台电脑得一直开着，而且家里宽带没有公网 IP，电信和联通的朋友互相连就是高延迟。存档还存在房主硬盘上，人换一台机器就接不上。

租一台云服务器跑专用服务端（Dedicated Server），这些问题一次解决：24 小时在线、存档在服务器、谁都能连、换电脑不影响。麻烦的地方在于，饥荒这个服务端的需求跟 Minecraft 完全不是一回事，按 MC 的思路买机器容易买错。

## 饥荒服务端到底吃什么资源

公开的实测整理给出的数字大致是：2~4 人时 CPU 占用 15~25%、内存 1~1.5GB，推荐最低 2 核 2G；6~12 人时 CPU 涨到 30~40%、内存 2~3GB，推荐 2 核 4G。也就是说这台机器上真正紧张的是内存，CPU 反倒没你想的那么吃。

社区教程里反复出现一句话——饥荒吃单核。原因是服务端的主世界逻辑要按 tick 顺序结算，很难拆到多个核心上并行跑。所以你买一台 4 核 2.5GHz 和一台 2 核 5.7GHz 的机器，前者核心多一倍，实际表现可能还不如后者。这一条直接决定了后面选机型的方向。

还有一个容易被忽略的点：开洞穴。

| 你要开的世界 | 建议配置 | 内存占用参考 |
| --- | --- | --- |
| 只开地面（6 人以下） | 1核2G | 1GB 左右 |
| 只开地面（6~12 人） | 2核2G / 2核4G | 1.5~2GB |
| 地面 + 洞穴双分片 | 2核4G 起 | 3GB 以上 |
| 地面 + 洞穴 + 一堆 mod | 4核8G | 看 mod 数量，可能 4GB+ |

洞穴是独立的一个分片进程，跟地面各跑一份世界数据。想开洞穴就得把内存预算翻倍，这是很多人买完机器才发现的事。

## 选机器真正要看的四件事

**内存。** 按上面那张表配，别省。内存不够的表现不是卡，是服务端隔几天莫名重启一次。

**单核主频。** 3.5GHz 以上比较舒服，能上 5GHz 级别的主频机器更好。核数给 2~4 核就够用了。

**上行带宽。** 6~12 人建议 5~8Mbps 上行。这个数字不吓人，因为饥荒传的是位置和状态同步，不是方块数据。反而要注意"不限流量"还是"大带宽限流量"——晚上玩两小时刷掉的流量比你想的多。

**机房位置。** 你和队友在哪个省，就选最近的机房。国内机房延迟普遍在 30ms 以内，跨运营商也能压住。

## 开服实操：七步跑起来

1. **买机器**。选 Ubuntu 22.04 或 Debian 系统，机房挑离你和队友最近的那个。
2. **配安全组**。入站放行 UDP 10800-12000（至少 10999），出站放通全协议。很多人只加了 TCP 10999，结果服务端启动正常、客户端永远连不上——饥荒通信走的是 UDP。
3. **装 SteamCMD**，执行 `app_update 343050 validate` 下载饥荒专用服务端。
4. **拿 Klei Token**。登录 Klei 账号，在"饥荒：联机版 → 游戏服务器"里生成，存成 `cluster_token.txt`。这个文件不对，服务端起不来。
5. **写配置**。`cluster.ini` 里设 `max_players`、`shard_enabled = true`；想开洞穴就把 `shard_count` 设成 2，Master 和 Caves 各跑一个进程。
6. **用 screen 或 tmux 启动**，别直接 SSH 里跑。SSH 一断服务端就跟着没了，这是新手最常见的"服务器莫名消失"。
7. **客户端连接**。游戏里按 `~` 打开控制台，输入 `+connect IP:端口` 就行。

## 几个一定会踩的坑

**饥荒更新后服务器列表里找不到自己的服。** 服务端版本落后于客户端时会这样，重新跑一遍 SteamCMD 更新即可。建议写个定时任务自动更新。

**mods 配置被覆盖。** 每次更新都可能重置 `dedicated_server_mods_setup.lua`，开服前备份一份，出问题直接还原。

**人数上限设太高。** `max_players` 写 20 但机器只有 2G 内存，结果就是固定时间点崩溃。按你实际会来的人设，宁少不多。

**带宽选错类型。** 温州、香港这类"大带宽限流量"机型，流量用完后会被限速到 5M 或 1M，能靠充值流量恢复。如果你队里有人爱挂机挂着不下线，选不限流量型更稳。

## 常见问题

**2 核 2G 够开饥荒吗？**
只开地面、6 人以下够用。想开洞穴，直接上 2 核 4G。

**几个人的话该选哪个机房？**
先看队友所在省份。江苏、浙江、上海一带选宁波、镇江、宿迁；华南选深圳节点；队伍里有港澳台或海外玩家，香港节点折中。

**机房带宽 10M 够用吗？**
够。饥荒同步的数据量不大，6~12 人建议 5~8Mbps 上行，10M 有余量。

**能不能先试用再决定？**
可以，云服务器和游戏云产品支持 1 元试用 1 天，每款限一次。先用最小机型测延迟，确认合适再换正式配置。
